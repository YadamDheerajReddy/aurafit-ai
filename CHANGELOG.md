# Changelog

All notable changes to AuraFit AI are documented here. The section for the
current tag is what users see in-app under Settings → Updates when a new
version is available.

## v0.3.0

- **Multi-profile support** — up to 3 profiles per device, Netflix-style.
  Each profile has its own goals, guardrails, logs, recipes, and diet
  plans, fully separate from the others. Switch or manage profiles anytime
  from Settings.
- **Log diet plan meals** — one tap to log any generated or saved diet plan
  meal straight into today's food log.
- **Sharper Describe** — the text meal-logging prompt now decomposes known
  dishes into their real components and gives one confident estimate per
  field instead of hedged ranges.
- **Branded installer** — a custom gradient-styled installer wizard on
  Windows and macOS, matching the app's own look.
- **In-app "what's new"** — Settings → Updates now shows what changed
  before you install an update.

## v0.2.0

- **Diet Plan generator** — a full one-day, 5-meal timetable generated from
  your calorie goal and cuisine preference, complete with a full recipe
  (ingredients + step-by-step instructions) for every meal.
- **Water tracking** — set a daily goal and log intake from the Dashboard.
- **Cuisine preference & ingredient avoid-list** — steer every recipe and
  diet plan away from ingredients you dislike, on top of allergies.
- **Styled PDF export** — export any diet plan as a branded, gradient-styled
  timetable PDF.
- **Personal details** — added a name field, shown across the app.
- Fixed Edit Profile silently dropping changes if the goal wasn't re-clicked.

## v0.1.0

- First packaged release: onboarding, biometric targets, quick-lookup and
  AI-described meal logging, the pantry recipe generator, progress charts,
  local data export, dark/light theme, and manual in-app update checks.
